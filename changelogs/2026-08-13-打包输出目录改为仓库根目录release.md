# 打包输出目录改为仓库根目录 release/

日期：2026-08-13

## 背景与方案

此前 electron-builder 的产物输出在 `packages/app/release/`，位置较深、不易查找。
本次将输出目录改到仓库根目录的 `release/`，方便直接在项目根下取包。

## 变更明细

- `packages/app/electron-builder.yml`：`directories.output` 由 `release` 改为
  `../../release`（该路径相对配置文件所在的 `packages/app` 解析，即仓库根目录）；
- 已有的旧产物目录 `packages/app/release/` 整体移动到根目录 `release/`。

## 影响评估

- `.gitignore` 中的 `release` 条目对任意层级的 release 目录都生效，根目录 `release/`
  同样被忽略，无版本控制影响；
- `pack:mac` / `pack:win` 脚本本身不涉及输出路径，无需改动；
- 代码与文档中无其他对旧输出路径的引用。
