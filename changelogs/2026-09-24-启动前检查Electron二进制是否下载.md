# 启动前检查 Electron 二进制是否已下载

## 变更方案

- 新增 `scripts/ensure-electron.mjs`：启动前通过 `electron/path.txt` + `dist/` 判断 Electron 可执行文件是否就绪；缺失时自动执行 electron 的 `install.js` 补下，默认使用 npmmirror 镜像（可用 `ELECTRON_MIRROR` 覆盖），下载失败则给出明确的手动重试命令并以非零码退出。
- `@youyi/app` 新增 `predev` 钩子（`node ../../scripts/ensure-electron.mjs`），npm 在 `npm run dev` 前自动执行，覆盖根目录 `npm run dev` 与工作区内的 `npm run dev -w @youyi/app` 两种入口。
- 已就绪时脚本静默跳过，不产生额外输出与网络请求。

## 影响评估

修复 `npm install` 阶段 Electron 二进制下载被网络中断后，`electron-vite dev` 抛 `Error: Electron uninstall` 的问题；正常已安装场景行为不变（仅多一次本地文件存在性判断）。仅影响开发启动流程，不改变构建产物与运行时行为。

## 验证

- `npm run predev -w @youyi/app`（Electron 已就绪时直接通过）
- `npm run dev`
