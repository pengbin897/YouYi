消息怎么流动
1Agent Hook 上报 任务事件到达哨兵
2微信通知 文本 + 引导语
3你回复 打字或语音，原样透传
4Agent 执行 回复与事件回传微信
能做的事
  • 继续/停止/重试透传给 Agent，由它理解执行
  • 新任务：xxx给最近活跃的 Agent 派活
  • 交给 Claude Code：xxx指定目标
  • 状态哨兵自答，不打扰 Agent
  • 全部停止紧急广播，需强确认
哨兵无 AI 对话能力：消息原样透传，语义由 Agent 自己理解。微信只支持文本/图片/语音，无卡片按钮。
